# 🎬 Netflix Content Analysis Dashboard (Power BI)

## 📌 Project Overview
This project focuses on analyzing Netflix's content library using Power BI to uncover insights about content distribution, genres, and release trends. The dashboard provides an interactive way to explore how Netflix content varies across countries, categories, and years.

---

## 📊 Objectives
- Analyze distribution of Netflix content by **genre, country, and release year**
- Identify **most popular genres and content types (Movies vs TV Shows)**
- Understand **year-wise growth of content on Netflix**
- Provide insights for **content strategy and audience preferences**

---

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard creation & visualization  
- **Excel / CSV** – Dataset  
- **Power Query** – Data cleaning & transformation  

---

## 📂 Dataset
- Netflix dataset containing information such as:
  - Title
  - Genre
  - Country
  - Release Year
  - Type (Movie/TV Show)

---

## 📈 Key Insights
- 📌 Movies dominate Netflix content compared to TV Shows  
- 📌 Certain genres like Drama and International content are highly frequent  
- 📌 Significant growth in content addition after 2015  
- 📌 Content distribution varies significantly across countries  

---

## 📊 Dashboard Features
- Interactive filters (Genre, Country, Year)
- KPI cards for quick insights
- Visuals showing:
  - Content distribution by type
  - Top genres
  - Country-wise content
  - Year-wise trends
